# NoSee

**NoSee 是一款 macOS 本地防窥提醒工具。**它通过摄像头检测画面中的人脸，并估计非本人是否正在看向屏幕；符合条件时，会在屏幕上显示醒目的提醒。

> NoSee 是实验性提醒工具。普通摄像头和视线估计模型可能漏报或误报，不能代替系统权限、屏幕隐私保护或其他安全措施。

## 功能

- 在 Mac 本机完成摄像头画面、人脸特征和视线方向分析。
- 录入本人后，监测画面中其他人是否可能看向屏幕。
- 旁人持续被判定为朝向屏幕时，显示“当心隐私信息泄漏，有人偷看”浮窗。
- 在菜单栏查看旁人数量、朝屏数量和身份匹配状态。
- 摄像头帧只在内存中处理；不会保存或上传原始画面。
- 本人特征和匹配阈值保存在当前 Mac 的钥匙串中，可随时清除。

## 环境要求

- macOS 13 或更高版本
- Python 3.12
- 可用的摄像头，并在 macOS“隐私与安全性”设置中允许终端或 NoSee 访问
- 首次安装模型时需要网络；之后推理可离线运行

依赖版本按 Python 3.12 配置。请勿使用 Python 3.14 创建虚拟环境；当前 PyTorch 依赖也固定在 `2.2.x` 版本范围内，以兼容本项目支持的 macOS 环境。

## 安装与启动

在项目目录打开终端，运行：

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
python run_app.py
```

也可以在安装依赖后使用命令行入口启动：

```sh
nosee
```

如果 `python3.12` 不存在，请先安装 Python 3.12，再重新创建虚拟环境。不同 Python 版本的虚拟环境不能直接互换。

## 安装离线模型

首次启动后，在 NoSee 控制面板选择 **安装离线模型**。程序会打开文件选择器，请选择 MPIIGaze 数据集中的：

```text
6 points-based face model.mat
```

如果还没有这个文件，请从 [MPIIGaze 官方页面](https://www.collaborative-ai.org/research/datasets/MPIIGaze/)获取数据集并解压。NoSee 不会自动下载这个数据集。选好文件后，程序会下载 GazeMap、SFace 和 MediaPipe 所需的其他模型文件，保存在：

```text
~/Library/Application Support/NoSee/models/
```

也可以通过命令行安装：

```sh
python -m nosee.install_models --face-model "/实际路径/6 points-based face model.mat"
```

模型文件不会存入本项目目录或随源代码上传。MPIIGaze 和 GazeMap 预训练权重有非商业使用限制；使用模型前请阅读[第三方许可说明](THIRD_PARTY_NOTICES.md)及上游许可。

## 使用方法

1. 启动 NoSee，并允许当前宿主应用访问摄像头。如果从终端启动，需要给“终端”授权。
2. 点击 **录入本人**。保持光线充足、画面中只有本人；先正对摄像头，再缓慢轻微向左、向右转头，等待采集 7 个样本完成。
3. 点击 **开始监控**。菜单栏会显示监控和身份状态。
4. 点击 **暂停监控** 可停止摄像头采集；点击 **清除本人资料** 会从钥匙串删除本人特征。

身份对齐方式更新后，旧的人脸档案会被拒绝用于监控；请重新录入本人。重新录入会覆盖钥匙串中的旧档案。

## 提醒逻辑与限制

- 单独检测到其他人脸不会触发浮窗；程序还需要估计该人正在看向屏幕。
- 当前触发条件是旁人被估计为朝向主显示屏约 0.6 秒。视线不可读或身份待确认时，状态栏会显示相应诊断信息。
- 摄像头位置、光线、距离、眼镜、脸部角度、屏幕布局和多人场景都会影响结果。
- 普通摄像头只能估算视线方向，不能保证识别所有旁观者，也不具备真正遮挡屏幕内容的能力。

## 隐私与本地数据

- 摄像头帧只在运行期间保留在内存中，不写入磁盘、不发送到网络服务。
- 本人特征向量和匹配阈值保存在 macOS 钥匙串中；可在应用中清除。
- 模型文件保存在用户的“Application Support”目录，不包含在 Git 仓库中。
